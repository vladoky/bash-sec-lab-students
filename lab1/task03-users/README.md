# Задание 3. Пользователи и группы

**Что делаем:** учимся отвечать на вопрос «кто я в этой системе» и читать
список пользователей.

## Шаг 1. Кто я

```bash
whoami
id
```

`id` показывает UID (числовой id), GID и группы. Запомните:
**UID 0 — это root**, всемогущий пользователь.

## Шаг 2. Список пользователей системы

Все локальные пользователи — в файле `/etc/passwd`:

```bash
grep -v '^#' /etc/passwd | head -5
```

> Нюанс: на macOS первые строки `/etc/passwd` — комментарии (начинаются
> с `#`), поэтому `head -5 /etc/passwd` покажет «пустоту». Команда выше
> отфильтровывает комментарии. И ещё: на macOS реальные учётные записи
> живут не в этом файле, а в Directory Service — `/etc/passwd` там
> используется только в single-user mode. На Linux-серверах (где и
> работает безопасник) файл основной.

Формат строки (через двоеточие):

```
имя : x : UID : GID : комментарий : домашний каталог : shell
```

## Шаг 3. Найдите «людей»

Служебных учёток много, настоящие пользователи обычно имеют UID ≥ 1000.
Отфильтруйте (вторая строка выводит заголовок-напоминание формата):

```bash
awk -F: '$3 >= 1000 {print $1, $3, $7}' /etc/passwd
```

(подробно awk разберём во второй лабораторной — пока просто выполните.)

## Шаг 4. Ответьте письменно

1. Чем root отличается от обычного пользователя с точки зрения UID?
2. Что плохого, если в `/etc/passwd` у «обычного» пользователя
   стоит UID 0?

## Результат

**В отчёт:** вывод `id` и список пользователей с UID ≥ 1000.
